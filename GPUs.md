# Supported GPUs

As for now, see https://pool.kryptex.com/device/gpu

Later, we will add a table with supported GPUs there.

The format should be something like:

```
Name (e.g. RTX 5090, but can be a GPU family for less popular devices, e.g. CDNA4; also group by family)
Supported or not (something like "Yes ✅" or "N/A❓" or "❌), 
Last known hashrate or estimate (e.g. 123.45 MH/s)
Last version that could have an impact on hashrate for that specific GPU (e.g. 1.5.0)
```
